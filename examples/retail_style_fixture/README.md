# Retail-style fixture (SIMULATED)

`transactions.csv.gz` is generated by `scripts/make_retail_fixture.py` (seed 2011). It copies only the **structure** of the
public UCI *Online Retail II* file so the adapter can be demonstrated and tested on a schema that differs from the
project's own synthetic data. **No value is real.**

| Property | This fixture | The project's synthetic demo data |
|---|---|---|
| Tables | 1 (transactions only) | 2 (customers + transactions) |
| Columns | Invoice, StockCode, Description, Quantity, InvoiceDate, Price, Customer ID, Country | customer_id, order_id, transaction_id, ... |
| Returns | invoice number starts with `C`, negative quantity | order id starts with `R`, negative quantity |
| Optional fields | no category, discount, registration date or demographics | all present |
| Dates | 2009-12-01 -> 2011-12-09, with time of day | 2024-01-01 -> 2025-12-31, date only |
| Customers | 2,000 (+ ~12% of rows with no Customer ID) | 6,000 |
| Non-product lines | `POST`, `M`, zero-price rows, exact duplicates | none |

Run it:  `python -m src.pipeline --config configs/retail_style_fixture.yaml`
